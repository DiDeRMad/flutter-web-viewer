# Epic MMORPG

Масштабная многопользовательская онлайн ролевая игра с полноценным игровым миром, системами прокачки, PvP и PvE контентом.

## 🎮 Основные возможности

### Игровой мир
- **Огромный открытый мир** с множеством зон, подземелий и рейдов
- **Динамическая погода** и смена дня/ночи
- **Живая экономика** с аукционом и торговлей между игроками
- **Глобальные события** и сезонный контент

### Персонажи
- **10+ игровых классов** с уникальными способностями
- **Глубокая система прокачки** с талантами и специализациями
- **Кастомизация внешности** персонажа
- **Маунты и питомцы**

### Боевая система
- **Динамичный экшн-бой** в реальном времени
- **PvP арены** и поля сражений
- **Масштабные рейды** на 40+ человек
- **Система комбо** и специальных приемов

### Социальные функции
- **Гильдии** с собственными залами и банками
- **Группы и рейды** с системой поиска игроков
- **Чат** с множеством каналов
- **Друзья** и черный список

### Крафт и профессии
- **10+ профессий** для изучения
- **Сложная система крафта** с рецептами
- **Сбор ресурсов** в открытом мире
- **Улучшение предметов** и зачарование

### Контент
- **1000+ квестов** с ветвящимися сюжетами
- **100+ подземелий** различной сложности
- **20+ рейдовых боссов**
- **Сезонные события** и праздники

## 🏗️ Архитектура

### Технологический стек

#### Backend
- **Node.js** + **TypeScript** - основа сервера
- **Express.js** - REST API
- **Socket.io** - real-time коммуникация
- **PostgreSQL** - основная база данных
- **Redis** - кеширование и сессии
- **Bull** - очереди задач

#### Frontend
- **React** + **TypeScript** - UI фреймворк
- **Three.js** - 3D графика
- **Redux Toolkit** - управление состоянием
- **Material-UI** - компоненты интерфейса
- **Socket.io-client** - связь с сервером

#### Инфраструктура
- **Docker** - контейнеризация
- **Kubernetes** - оркестрация
- **nginx** - балансировка нагрузки
- **Prometheus** + **Grafana** - мониторинг

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- PostgreSQL 14+
- Redis 6+
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/epic-mmorpg.git
cd epic-mmorpg
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта:
```env
# Database
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=epic_mmorpg

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379

# JWT
JWT_SECRET=your-secret-key
JWT_REFRESH_SECRET=your-refresh-secret

# Server
PORT=3000
SOCKET_PORT=3001
```

4. Создайте базу данных:
```bash
createdb epic_mmorpg
```

5. Запустите миграции:
```bash
npm run migrate
```

6. Запустите проект в режиме разработки:
```bash
npm run dev
```
